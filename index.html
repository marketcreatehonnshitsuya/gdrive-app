Gドライブ

「Gドライブ」は、オーナーが個人で使うためのツールです。rclone を使って、オーナー自身の Google ドライブのフォルダと、オーナー自身のサーバーを同期します。

A personal tool that syncs the owner's own Google Drive folder with the owner's own server using rclone.

  • 一般公開のサービスではありません。オーナー本人だけが使います。
  • アクセスするのはオーナー自身のドライブのファイルだけです。

プライバシーポリシー（Privacy Policy）

連絡先は、Google の同意画面に記載のデベロッパー連絡先をご覧ください。
